Books that balance

Not attempted

On Arc, native USDC and the USDC token are the same balance. A token transfer to your contract adds to its native balance without running any of its code, and the token's balanceOf rounds down anything below 0.000001 USDC. Write a vault whose books stay right anyway.

function learner() external view returns (address);
function deposit() external payable;
function totalAssets() external view returns (uint256); // in wei, 18 decimals
function withdrawAll(address payable to) external;

The checker deposits a random amount with dust, sends 0.000001 USDC by token transfer, checks totalAssets(), then withdraws everything. It runs the test inside a call it reverts, so no money moves.

Post-quantum signature

Not attempted

Arc verifies SLH-DSA-SHA2-128s signatures, a post-quantum scheme, in a precompile at 0x1800…0004. You sign a message bound to your address with your own key. Your contract must accept that signature and reject a tampered copy.

function learner() external view returns (address);
function verify(bytes calldata vk, bytes calldata message, bytes calldata sig)
    external view returns (bool);
